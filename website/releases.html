Opening the app.

macOS: extract the ZIP and open MultiCAD.app. The Apple silicon build is ad-hoc signed and has not been notarized by Apple.

Windows: extract the whole ZIP into a folder, then run multicad.exe. Keep its resources folder beside it. The build is unsigned.

Linux: extract the ZIP and run ./multicad on an Ubuntu 24.04 or newer desktop with graphics drivers.

No Python or Node.js installation is needed. For another platform, build from source.
