ToskCAD visual direction: light azure blue (#519DCE target) with white text and fine, subtly hand-drawn technical lines, sparse construction guides and a quiet blueprint grid. The current app icon and logo emblem read TK C: smaller uppercase TK beside a dominant isometric C, with no strike-through. The full logo wordmark reads ToskCAD. Files with the -tk-c suffix follow this revised direction; earlier unsuffixed artwork is retained as an initial concept. The future website should use this same light-blue blueprint treatment, inspired by classic Apple developer websites; it has not been built in this branding step. Artwork is for visual review, with native icon packaging and application-name migration left to a separate implementation step.
