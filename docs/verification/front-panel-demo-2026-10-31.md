# C-channel front panel demo (CAD-184), 2026-10-31

The shipped example `examples/front-panel.tcd` ("C-channel front panel") is
generated by `cargo run -p multicad-app --example front_panel_demo -- examples/front-panel.tcd [EXPORT_DIR]`.
The generator uses the typed transaction API that the UI and MCP share; with an
export directory it also writes every deliverable and a `manifest.json`.

## Design choices

| Item | Value |
|---|---|
| Sheet | EN AW-5754 H22, 1.5 mm stock; inside radius `bend_radius` 1.5 mm and K `k_factor` 0.44 as part overrides |
| Section | Flat front on XZ, `panel_width` 260 × `panel_height` 80 mm between the bends; top and bottom 90° flanges bent back, `flange_depth` 40 mm leg. The outer height is `panel_height` + 2 × (`bend_radius` + `sheet_t`) |
| Buttons | Six placements of one illustrative 12 mm push button (Ø15 cap, Ø12 bushing, Ø16 nut) in Ø`button_hole` 12.5 holes, two rows of three from `button_x`, `button_pitch`, `button_rows` |
| Display | One illustrative 16×2 module (80 × 36 board, holes 75 × 31, 71 × 24 frame) behind a 72 × 25 window on four M3 × `display_standoff` hex standoffs (AF 5.5) |
| End parts | PETG, sketched and extruded in print orientation (outer face on the plate, +Z build), rotated into place. A 4 mm plate covers the outer C profile; a 16 mm plug fills the C with 0.3 mm clearance. The right part has a Ø8 cable hole |
| Fastening | ISO 4762 M3 × 8 through ISO 273 clearance holes in both flanges, 8 mm from each end, into Ø4 × 8 pilot holes for M3 heat-set inserts |

Buttons and display are illustrative envelopes with typical nominal sizes, not
cited manufacturer data. `sheet_t` mirrors the stock thickness for the printed
parts and button caps; keep it equal to the stock.

## Deliverables

- Four A3 pages: assembled views with the hardware table; an exploded arrangement
  of separate views spaced along X; the sheet's folded views with the bend table;
  the end parts in print orientation with the BOM.
- Export sets selected by tag: drawings (PDF, drawing DXF), the sheet STEP, and one
  print set per end part (3MF and STEP, tags `printed` + `left-end`/`right-end`).
- The developed blank (`front-panel-developed.dxf`) and BOM, bend and hardware CSVs.
- File metadata: name, description and a GPU-free rendered 640 × 400 preview.

## Supporting model change

The sheet and every component are definition Parts of one placed assembly. Drawing
views now accept an assembly member Instance (projected at its placed pose when one
placed copy holds it) and a definition Part (shown in its own coordinates). Sheet
records, hardware records and unfolding use the definition head of a sheet Part an
assembly places. Covered by `crates/multicad-model/tests/assembly_definition_sources.rs`.

## Evidence and limits

`crates/multicad-app/tests/front_panel.rs` opens the shipped file. It checks the
metadata, the folded and developed geometry, the openings and fits, which use
zero-volume intersections, and the drawing views. It also checks edits with
Undo/Redo and save/reopen, and that the generator still produces the same structure
and deliverables.

These items are not available in this build or not verified:

- **Not available:** flat-pattern and exploded drawing views. The developed DXF and
  the separate-view arrangement replace them. The viewport Explode tool remains
  presentation only.
- **Not verified:** interactive macOS review, Windows/Linux runtime, press-brake
  tooling or springback, and physical print or fit.
- **Not implemented here:** discovery in Examples and on no-recents launch (CAD-186).
