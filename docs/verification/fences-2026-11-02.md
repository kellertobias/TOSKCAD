# Fence construction and run verification

CAD-205 implements canonical fence constructions, bounded flat-run layout,
independent native members, graphical component authoring, typed MCP controls
and linked drawing output. The final Rust validation source is `bf2ba3c` on
`main`. Actual macOS graphical interaction and CAD-206 Library integration
remain incomplete; this record does not establish human acceptance.

## Verification

On the final Rust source:

- `cargo fmt --all -- --check`: passed.
- `cargo clippy --workspace --all-targets --locked -- -D warnings`: passed.
- `cargo test --workspace --locked --no-fail-fast`: exit 0; 2,198 passed,
  zero failed and four ignored across 252 result groups, including doctests.

The four default skips are the interrupted-writer subprocess helper, the
Blender-dependent case and two physical-GPU tests. This run does not claim
fresh interactive macOS or Windows/Linux execution.

Focused checks included nine native fence integration tests, four MCP fence
tests and five real stdio protocol tests. Earlier frozen UI/core checkpoints
passed 855 UI tests with two hardware skips and 489 core tests without skips.
The final whole-workspace run includes those components.

Native evidence covers measured independent post, panel, rail and picket
solids; exact round posts; L/closed/rotated layouts; explicit panel cuts;
overlap refusal; STEP readback; TCD rebuild; cancellation/retry; and cache
validation before accepting a warm member result. Component/native-worker
checks exercise painted bay selection, shared/duplicate controls, snapped
viewport paths, explicit post repair, Preview/Cancel/Apply, history and reopen.
These are production-component checks rather than native-window interaction.

Linked plan/elevation fixtures independently parse PDF strokes and DXF geometry
at 1:100, 1:50 and 1:10. They measure 90 mm posts, 1,910 mm full clear panel
spans, a 410 mm short final panel and the physical elevations. A native
face-associated overall dimension updates from 4,590 mm to 4,890 mm after
moving the last path vertex, retaining member Part IDs. The BOM contains four
Timber posts and three Metal panels, each with quantity one. Poppler reads the
600 × 500 mm PDF pages and dimension text; raster renders were inspected.

The first whole-workspace attempt failed an existing discovery assertion that
equated a required revision with mutation. Read-only fence preview deliberately
guards its revision without committing. The correction explicitly checks both
properties for that tool and preserves the previous assertion for every other
tool. The focused protocol tests and complete workspace rerun then passed.
Production behavior did not change after `fa79ef4`.

Local ignored evidence is retained under
`artifacts/fence-review-20261101/`: the final workspace log, focused logs,
`ui-mcp-drawing-checkpoint.json` with source and artifact hashes, and native
TCD/PDF/DXF/SVG/Poppler-PNG fixtures in `drawings/`. A PLAINER attachment attempt
did not add files; local files are the review fallback.

## Remaining acceptance

Actual macOS type creation, viewport drawing and later editing still require
interactive verification. The native UI-control tool was unavailable during
this implementation; no new desktop windows were opened for these checks.
Native-project dynamic-symbol authoring, cross-project Library placement,
typed path/context materialization and explicit pinned upgrades belong to
[CAD-206](https://plans.tokenet.de/CAD/206) and remain unimplemented here.

Terrain following, stepped/raked slopes, gates and engineered foundations are
outside this flat-run implementation. Rectangular-post paths support straight
and right-angle turns; round posts permit other nondegenerate turns subject to
native collision validation. Unsupported configurations fail without partial
commit. CAD-205 must retain its remaining graphical and Library acceptance gaps.
