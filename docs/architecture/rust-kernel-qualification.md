## Performance and release evidence

The Toolcase measurement covers the optimized model compiler. It records 237 ms and 211 ms medians across five paired ARM64 runs of a primitive edit. The Apartment AP-102 worker measured about 5 ms for a persisted preview cache hit. These intervals end before viewport rendering. [Working Log](https://plans.tokenet.de/CAD/290) · [Drawing worker fixture](../../crates/multicad-app/src/drawings.rs)

The proposed cutover workloads include the cold 24/36 continuous herringbone pair, a cold modeled M8 × 1.25 × 50 mm thread, and operator-visible parameter edits for Toolcase and Control Desk. The [performance contract](https://plans.tokenet.de/CAD/290) specifies the paired baselines, sample counts, resource budgets and stop latency. The bounded spur fixture supplies clearance evidence for the straight-tooth case. Herringbone performance remains open.

At the code pin, the pure Rust kernel measured 30,488 of 30,488 lines and 3,536 of 3,536 functions with `cargo llvm-cov --locked -p multicad-rust-kernel --fail-under-lines 100 --fail-under-functions 100`. Full workspace coverage, the required runtime workflows, and geometry equivalence are separate checks. Windows and Linux packages, macOS interactive acceptance, and the full locked workspace gate on the cutover commit remain open.
