## Performance and release evidence

The Toolcase measurement covers the optimized model compiler. It records 237 ms and 211 ms medians across five paired ARM64 runs of a primitive edit. The Apartment AP-102 worker measured about 5 ms for a persisted preview cache hit. These intervals end before viewport rendering. [Working Log](https://plans.tokenet.de/CAD/290) · [Drawing worker fixture](../../crates/multicad-app/src/drawings.rs)

In 24 interleaved pairs with the same debug binary, the detached FP-101 drawing worker median was 839 ms with OpenCascade and 97 ms with Rust. The fresh-worker disk cache medians were 48 ms and 19 ms. Both cold paths evaluated 29 source features, and the disk restores performed no rebuild. The worker measurement ends when the drawing payload is ready. [Working Log](https://plans.tokenet.de/CAD/290)

The signed candidate handled the custom modeled M8 × 1.25 × 50 mm MCP request in 2.309 ms median and 13.245 ms p95 across 20 fresh processes. Each run checked one solid, volume and bounds. The cutover contract also calls for a matched release-build comparison, a desktop Preview-to-ready measurement, the cold 24/36 continuous herringbone pair, and operator-visible Toolcase and Control Desk parameter edits. [Performance contract](https://plans.tokenet.de/CAD/290)

The pure Rust kernel at `b2b76200` measured 31,140 of 31,140 lines and 3,594 of 3,594 functions with `cargo llvm-cov --locked -p multicad-rust-kernel --fail-under-lines 100 --fail-under-functions 100` in a fresh coverage target with development debug information and incremental compilation disabled. Full workspace coverage, runtime workflows and geometry equivalence are separate checks. Windows and Linux packages, macOS interactive acceptance, and the full locked workspace gate on the cutover commit remain open.
