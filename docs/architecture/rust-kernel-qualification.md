## Performance and release evidence

Across 16 interleaved pairs per fixture with the same optimized ARM64 binary, the cached Toolcase rail-pitch edit took 222 ms median with OpenCascade and 5.9 ms with Rust. The Control Desk width edit with footprint envelopes took 629 ms and 4.9 ms. The full linked-STEP Control Desk rebuilt in 7.5 ms median in Rust. That fixture embeds Rust STEP geometry, so the matched comparison uses the footprint-envelope variant. These measurements include display publication and end before viewport rendering. [Working Log](https://plans.tokenet.de/CAD/290)

In 24 interleaved pairs with the same optimized ARM64 binary at `b2b76200`, the detached FP-101 drawing worker median was 681 ms with OpenCascade and 12 ms with Rust. The Rust p95 was 22 ms. The fresh-worker disk cache medians were 7.6 ms and 3.1 ms, with no rebuild. Rust's same-session cache returned the retained payload synchronously. The isolated scoped rebuild dropped from 580 ms to 4.5 ms, and projection from 109 ms to 3.8 ms. The worker measurement begins with an open project and ends when the drawing payload is ready. [Working Log](https://plans.tokenet.de/CAD/290)

The custom modeled M8 × 1.25 × 50 mm MCP request took 7.579 s median with OpenCascade and 2.001 ms with Rust in 20 interleaved fresh-process pairs using the same optimized ARM64 executable at `57f80438`. The p95 values were 11.940 s and 3.291 ms. Every run checked one solid, its bounds and its volume. The signed Rust-only candidate independently measured 2.154 ms median across 20 fresh processes. The cutover contract also calls for desktop Preview-to-ready, the complete cold 24/36 continuous herringbone pair, and operator-visible Toolcase and Control Desk parameter edits. [Performance contract](https://plans.tokenet.de/CAD/290)

The saved 24/36 continuous herringbone pair took 22.717 s median with OpenCascade and 84.801 ms with Rust in 20 interleaved fresh-process pairs using the same optimized ARM64 executable at `d0ddf69b`. The p95 values were 25.272 s and 97.399 ms. Every request checked all nine cycle poses and the current pose, both gear placements, assembly bounds and volume. Median process CPU time fell from 134.23 s to 0.08 s, and median peak resident memory fell from 1,791 MB to 99 MB. The signed Rust-only candidate independently measured 86.494 ms median. These timings measure the command response. [Working Log](https://plans.tokenet.de/CAD/290)

The pure Rust kernel at `0d44eb49` measured 37,228 of 37,228 lines and 4,209 of 4,209 functions with `cargo llvm-cov --locked -p multicad-rust-kernel --fail-uncovered-lines 0 --fail-uncovered-functions 0` in an isolated target with development debug information and incremental compilation disabled. The same revision passed 80 kernel facade unit tests, 55 Rust-only application worker and protocol tests, strict workspace Clippy, and the workspace doctests.
